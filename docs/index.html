OPlayer 미디어 플레이어

내 미디어를, 내가 선택한 저장소에서.

OPlayer는 로컬 파일과 네트워크·클라우드 저장소의 영상·오디오·사진을 재생하고, 내장 브라우저와 다운로드 기능을 제공하는 오픈 소스 앱입니다.

앱 다운로드소스 코드

지원 플랫폼과 다운로드

Android 휴대폰·태블릿과 Android TV, Windows·Linux x64/ARM64, macOS Apple Silicon용 배포 파일을 제공합니다. 최신 정식 버전 다운로드·릴리즈노트에서 기기에 맞는 파일을 선택하세요.

주요 기능

  • 로컬 파일과 SMB·FTP·SFTP·WebDAV, 사용자가 설치한 클라우드 확장앱의 파일 탐색·재생
  • 내장 브라우저, 미디어 다운로드, 자막·플레이어 설정, 재생목록·이어보기
  • 선택적 Google 계정 동기화: 재생목록·최근 재생·재생 위치를 사용자 Google Drive의 앱 전용 공간에 보관
  • Google Drive 확장앱: 사용자가 연결한 계정의 파일 목록·검색·읽기와 직접 선택한 위치로의 업로드
  • 선택적 앱·리소스 잠금, 캡처 방지, DNS over HTTPS와 네트워크 설정

Google 연결과 개인정보

Google 연결은 선택 사항이며, 로컬 재생을 위해 Google 계정을 연결할 필요는 없습니다. 동기화와 일반 Drive 접근은 별도의 기능·토큰으로 관리합니다. 개발자가 운영하는 별도 동기화 서버는 사용하지 않습니다.

데이터 종류·이용 목적·전송 대상·보관 및 삭제 방법은 개인정보처리방침에서, 앱 이용 조건은 이용약관에서 확인할 수 있습니다.
